# Morse Light 🔦

Android-приложение для передачи сообщений азбукой Морзе через вспышку телефона.

## Возможности

- 💡 **Ручной фонарик** — простое включение/выключение
- 📡 **Передача текста** — введи любое сообщение (русские и английские буквы), и фонарик мигнёт его кодом Морзе
- 🆘 **Режим SOS** — мгновенный сигнал бедствия (`... --- ...`)
- ⚡ **Регулировка скорости** — ползунок от 5 до 30 слов в минуту
- 🟡 **Визуальная индикация** — на экране светится круг синхронно с фонариком

## Технологии

- **Язык:** Kotlin
- **UI:** Jetpack Compose
- **Архитектура:** Android ComponentActivity
- **Минимальный SDK:** API 21 (Android 5.0)

## Как работает

Приложение использует `CameraManager.setTorchMode()` для управления вспышкой. Текст конвертируется в последовательность точек и тире по стандартной азбуке Морзе (поддерживаются русские и латинские буквы, цифры). Длительность сигнала рассчитывается по формуле `1200 / WPM` миллисекунд на единицу времени.

## Разрешения

Никаких разрешений не требуется! Управление фонариком в Android доступно без CAMERA-permission.
